# ssb-app
Government-grade DevOps &amp; SRE delivery platform for a Go microservice. Features multi-stage distroless Docker builds, Helm charts, GitHub Actions CI/CD with Trivy &amp; Cosign, Argo CD GitOps, Kyverno policies, Terraform EKS IaC, and Prometheus/Grafana monitoring.
